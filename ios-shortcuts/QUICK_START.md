# Quick Start: iOS Note Recording Shortcut

Choose your preferred method to get the shortcut on your iPhone:

## ⚡ Fastest Method: Use the Pre-Built File

**If you already have this repository on your computer:**

1. **Transfer the file to your iPhone** (choose one):
   - **AirDrop**: Right-click `RecordToNote.shortcut` → Share → AirDrop → Your iPhone
   - **iCloud**: Upload to iCloud Drive, open on iPhone
   - **Email**: Email it to yourself, open on iPhone

2. **Import**:
   - Tap the file on your iPhone
   - Tap "Add Shortcut"
   - Grant permissions when asked

3. **Done!** The shortcut is ready to use.

**See `IMPORT_INSTRUCTIONS.md` for detailed steps.**

---

## 🤖 Alternative: Ask Claude Browser to Generate It

**If you want Claude to create it for you:**

### Option 1: Use the Simple Prompt

1. Go to [claude.ai](https://claude.ai)
2. Copy the entire contents of `SIMPLE_CLAUDE_PROMPT.txt`
3. Paste into Claude
4. Claude will generate the .shortcut file code
5. Copy the code and save as `RecordToNote.shortcut`
6. Transfer to iPhone and import

### Option 2: Use the Detailed Prompt

1. Go to [claude.ai](https://claude.ai)
2. Open `CLAUDE_BROWSER_PROMPT.md`
3. Copy everything between "PROMPT START" and "PROMPT END"
4. Paste into Claude
5. Follow the instructions Claude provides

---

## 🛠️ Manual Method: Build It Yourself

**If you prefer to create it manually in the Shortcuts app:**

1. Open the Shortcuts app on your iPhone
2. Follow the step-by-step guide in `NOTE_RECORDING_SHORTCUT.md`
3. Takes about 2-3 minutes

## After Installation

### Using the Shortcut
- Tap it in the Shortcuts app
- Or say "Hey Siri, Record to Note"
- Or add to home screen for one-tap access

### Customization
- **Change name**: Long-press → Rename
- **Change icon**: Tap shortcut → Tap icon
- **Add to Siri**: Tap shortcut → "Add to Siri"
- **Add to home screen**: Tap shortcut → Settings → "Add to Home Screen"

### Finding Recordings
- Open Notes app
- Look for "Voice Recordings" note
- All recordings are timestamped there
